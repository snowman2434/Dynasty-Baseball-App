What's inside
Built for the way leagues actually run.
⚡
Live auction room
Real-time bidding with countdown timers. Regular or slow auction modes supported.
💰
Budget tracker
Each team's remaining budget shown live. Know how aggressive you can get before blowing your cap.
🗂
Multi-nomination
Configure how many players each team can put up simultaneously. Multiple blocks run in parallel.
🏆
Keeper support
Assign keepers per team before the auction. Prices are deducted automatically from budgets.
📋
Full roster view
See every team's roster with all position slots — filled and empty — at any point during the draft.
🔧
Custom positions
Configure exactly which roster slots your league uses — C, MI, CI, UTIL, BENCH, MiLB, and more.
